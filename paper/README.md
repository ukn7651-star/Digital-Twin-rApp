# Paper

IEEE conference draft for the digital-twin platform.

- `main.tex` — the paper source (IEEEtran conference class).
- `main.pdf` — a pre-compiled copy.
- `fig_cdf_pooled.png`, `fig_outage_vs_load.png`, `fig_throughput_vs_load.png` —
  figures (generated by `python -m dtrapp.runner.sweep`).

## Build

**On Overleaf:** create a project, upload `main.tex` and the three `fig_*.png`,
set the compiler to **pdfLaTeX**, and compile.

**Locally:**
```bash
pdflatex main.tex && pdflatex main.tex
```
(Two passes resolve references. A minimal TeX Live with `texlive-latex-recommended`,
`texlive-publishers` (IEEEtran), and `texlive-science` (algorithm) is sufficient.)

The document compiles even if the figures are absent (placeholder boxes are shown),
so `main.tex` alone will build.
